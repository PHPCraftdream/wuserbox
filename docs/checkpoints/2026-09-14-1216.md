## Decisions

- Chose a machine-wide shared SID for the agent preset over any per-file
  interception or symlink trick, because a junction does not change where
  Windows evaluates an ACL — it still checks the real target's own entries —
  so nothing but reducing how many principals need one saves the repeated
  cost.
- Chose to require a dash on every command rather than special-case only the
  ones that collide with likely program names, because the simpler, uniform
  rule ("nothing without a dash is a command") cannot be defeated by a future
  program whose name happens to match a future command.
- Chose `git commit-tree`-based checkpoint commits and `robocopy /E` (not
  `/MIR`) for the repo copy — non-destructive, leaves the source untouched
  until explicitly asked to remove it.
- Chose to leave the old directory at `C:\Users\Computer\Desktop\pc\wuserbox`
  in place rather than delete it proactively, since deleting it while this
  session's shell still reset there before every command would have broken
  the session's own ability to run further commands.
